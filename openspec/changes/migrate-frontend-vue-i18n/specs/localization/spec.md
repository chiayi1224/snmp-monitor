# Spec Delta

## Purpose

定義系統支援的介面語言、使用者看到的語言如何決定與切換，以及網頁介面文字、後端 API 訊息與系統產生之文字在各語言下的呈現方式。

## ADDED Requirements

### Requirement: 支援的語言
系統 SHALL 支援正體中文（`zh-TW`）、簡體中文（`zh-CN`）與英文（`en`），預設為正體中文。三種語言 SHALL 涵蓋相同的介面文字與訊息；某語言缺少某則訊息時 SHALL 改用正體中文顯示，SHALL NOT 顯示訊息代碼本身。

#### Scenario: 三種語言內容一致
- **WHEN** 檢查前端與後端的三份語系內容
- **THEN** 三種語言具有完全相同的訊息代碼集合

### Requirement: 介面語言的決定與切換
網頁介面 SHALL 依下列順序決定語言：使用者先前選擇的語言；否則依瀏覽器偏好語言（繁體中文相關 → `zh-TW`、簡體中文相關 → `zh-CN`、英文 → `en`）；都不符合時為 `zh-TW`。使用者 SHALL 可在登入畫面與已登入的每個畫面切換語言，切換後立即生效、不需重新登入，並在之後開啟時沿用。

#### Scenario: 首次使用英文瀏覽器
- **WHEN** 瀏覽器偏好語言為 `en-US`，使用者第一次開啟介面
- **THEN** 介面以英文顯示

#### Scenario: 簡體中文瀏覽器
- **WHEN** 瀏覽器偏好語言為 `zh-CN` 或 `zh-Hans`
- **THEN** 介面以簡體中文顯示

#### Scenario: 切換並記住
- **WHEN** 使用者在頁首把語言切換為簡體中文，之後關閉瀏覽器再開啟
- **THEN** 切換當下所有可見文字立即變為簡體中文；再次開啟時仍為簡體中文

#### Scenario: 不支援的語言
- **WHEN** 瀏覽器偏好語言為 `ja-JP`，且使用者未曾選擇語言
- **THEN** 介面以正體中文顯示

### Requirement: 介面文字與格式隨語言切換
網頁介面中所有固定文字（選單、標題、按鈕、欄位名稱、提示、確認對話框、表格的空白提示）SHALL 依目前語言顯示；UI 元件內建文字（例如分頁、日期選擇、空白資料）與日期時間格式 SHALL 隨語言切換。使用者輸入的資料（設備名稱、Trap 描述、自訂範本名稱等）SHALL 原樣顯示，不翻譯。

#### Scenario: 英文介面的日期
- **WHEN** 介面為英文時顯示告警時間
- **THEN** 時間以英文的日期格式呈現，畫面上沒有中文的固定文字

### Requirement: 後端訊息依請求語言回傳
後端 API 回應中給使用者看的錯誤與成功訊息 SHALL 依請求的 `Accept-Language` 標頭以對應語言產生，規則與介面相同；沒有該標頭或不支援時 SHALL 為正體中文。網頁介面 SHALL 在每個 API 請求帶上目前的介面語言。

#### Scenario: 英文錯誤訊息
- **WHEN** 以 `Accept-Language: en` 新增一筆 Warning 高於 Critical 的閾值
- **THEN** API 回應 HTTP 400，錯誤訊息為英文

#### Scenario: 未指定語言
- **WHEN** 外部程式以不帶 `Accept-Language` 的請求登入成功
- **THEN** 回應訊息為正體中文（與升級前相同）

### Requirement: 系統產生之文字依讀取時的語言顯示
系統自動產生並保存的文字——告警描述（例如連線中斷原因、閾值已移除、設備已刪除）、稽核日誌說明、OID 掃描的進度、錯誤與 MIB 探測名稱及取樣——SHALL 在讀取時依請求語言顯示，同一筆記錄可被不同語言的使用者以各自的語言閱讀。升級前已保存的舊記錄 SHALL 原樣顯示。Trap 的原始 VarBind 內容 SHALL 原樣顯示。

#### Scenario: 同一筆告警不同語言
- **WHEN** 系統記錄一筆「SNMP 無回應」的連線中斷告警，之後分別以英文與簡體中文查詢告警
- **THEN** 英文查詢看到英文描述，簡體中文查詢看到簡體中文描述

#### Scenario: 升級前的舊告警
- **WHEN** 查詢一筆升級前以正體中文保存描述的告警，請求語言為英文
- **THEN** 描述以原本的正體中文顯示

### Requirement: 內建項目的顯示名稱
內建監控範本的名稱與說明、系統設定項目的說明 SHALL 依請求語言顯示；其識別用的名稱與設定鍵 SHALL 維持不變，不影響既有資料與 API 呼叫。

#### Scenario: 英文介面看內建範本
- **WHEN** 以英文介面開啟監控範本頁
- **THEN** 「HOST-RESOURCES 通用」顯示為英文名稱，套用規則與設備的手動指定不受影響

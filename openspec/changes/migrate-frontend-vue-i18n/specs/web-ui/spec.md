# Spec Delta

## Purpose

定義網頁管理介面如何交付給瀏覽器、在沒有網際網路的環境中如何運作、涵蓋哪些管理功能，以及登入、強制改密碼與登入失效時的畫面導向規則。

## ADDED Requirements

### Requirement: 單頁應用由 JAR 提供
網頁介面 SHALL 以單頁應用的形式包含在應用程式 JAR 中，並由內建的 Web 伺服器在根路徑 `/` 提供。不同功能以前端路由切換，切換時 SHALL NOT 重新載入整個頁面。

#### Scenario: 開啟首頁
- **WHEN** 使用者以瀏覽器開啟 `http://<主機>:<port>/`
- **THEN** 瀏覽器取得網頁介面；未登入時顯示登入畫面

#### Scenario: 舊頁面網址
- **WHEN** 使用者開啟升級前的 `/login.html`
- **THEN** 不會顯示舊的登入頁，而是被導向新的網頁介面

### Requirement: 完全離線可用
網頁介面執行時所需的所有資源（程式、樣式、圖示、字型、語系檔）SHALL 由本系統提供。網頁介面 SHALL NOT 向本系統以外的任何網址發出請求，在沒有網際網路的環境中所有功能 SHALL 正常運作。

#### Scenario: 無網際網路
- **WHEN** 瀏覽器只能連到本系統、無法連到任何外部網址
- **THEN** 登入、各功能頁、語言切換都正常運作，且瀏覽器沒有任何被阻擋或失敗的外部請求

### Requirement: 功能涵蓋
網頁介面 SHALL 提供下列功能，行為與升級前的網頁相同：各設備目前狀態（含最高未解除告警等級）、設備管理（含 SNMP v1／v2c／v3 設定、監控範本、磁碟過濾與磁碟探測、連線中斷告警）、OID 探索、監控範本（含試算）、Trap 對應（含未定義 Trap 與未登錄來源）、每台設備的閾值設定（含套用到其他設備）、告警記錄（含等級、設備、未解除篩選）、帳號管理、API Token、稽核日誌、系統設定（含資料保存期限）。

#### Scenario: 管理者操作設備
- **WHEN** 管理者在設備管理新增一台 v3 設備、探測磁碟並勾選要監控的掛載點後儲存
- **THEN** 設備以相同設定被建立，與升級前網頁的結果一致

#### Scenario: 顯示伺服器回傳的文字
- **WHEN** 設備名稱、Trap 描述或任何伺服器回傳的文字含有 `<script>` 等 HTML
- **THEN** 介面將其顯示為純文字，不會執行

### Requirement: 登入與登入失效導向
未登入或登入已失效時，網頁介面 SHALL 顯示登入畫面；登入成功後 SHALL 進入原本要前往的功能頁（沒有時為狀態頁）。任何 API 回應 401 時，網頁介面 SHALL 回到登入畫面。

#### Scenario: 登入後回到原頁
- **WHEN** 未登入的使用者開啟告警記錄頁的網址，登入成功
- **THEN** 畫面進入告警記錄頁

#### Scenario: 被管理員撤銷登入
- **WHEN** 使用者正在使用介面時，管理員重設了他的密碼
- **THEN** 他下一次操作時介面回到登入畫面

### Requirement: 強制改密碼
帳號需要改密碼時（例如預設帳號首次登入），網頁介面 SHALL 在登入後只顯示修改密碼畫面，修改成功前 SHALL NOT 顯示其他功能頁。

#### Scenario: 預設帳號首次登入
- **WHEN** 使用者以 `admin` / `admin` 首次登入
- **THEN** 介面只顯示修改密碼畫面；改密碼成功後進入狀態頁

### Requirement: 前端外殼公開、資料受保護
網頁介面的外殼（首頁與其靜態資源）SHALL 不需登入即可取得，且 SHALL NOT 包含任何設備、告警、帳號或設定資料；所有資料 SHALL 仍只能透過需要認證的 API 取得。

#### Scenario: 未登入取得靜態資源
- **WHEN** 未登入的請求取得首頁與其程式檔
- **THEN** 回應成功，內容不含任何資料庫中的資料；未登入呼叫 `/api/admin/devices` 仍回應 401

### Requirement: 升級後不使用舊版快取
首頁 SHALL 每次都向伺服器確認是否有新版本；內容帶版本雜湊的靜態資源 SHALL 可長期快取。升級後使用者重新整理頁面 SHALL 取得新版介面，不需要清除瀏覽器快取。

#### Scenario: 升級後重新整理
- **WHEN** 系統升級到新版本，使用者在原本開著的瀏覽器分頁按重新整理
- **THEN** 顯示新版介面
